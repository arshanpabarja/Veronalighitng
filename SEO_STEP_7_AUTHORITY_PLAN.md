## Submission package

Create one cloud folder per project containing:

- 12–20 high-resolution landscape and portrait images where available
- Photographer permission and exact photo credit
- Project name, city, year, type, and full participant credits
- 250–400-word Persian description
- 250–400-word English description
- 100-word lighting-design note
- Verona logo in PNG
- Canonical project URL
- One contact name, email, and telephone

Never send images without written permission to publish.

## Anchor-text policy

Across earned links:

- 60–70%: Verona Lighting, ورونا لایتینگ, or the naked homepage URL
- 20–30%: project names or descriptive brand phrases
- 0–10%: natural partial phrases such as «نورپردازی ویلای رویان»
- Do not request repeated exact-match anchors such as «خرید چراغ خطی توکار»

The publication should normally link to the matching project page. A contextual
second link to a technical guide or category page is useful only when it helps
the reader.
